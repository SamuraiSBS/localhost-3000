# Проверки рабочего дизайна — 2026-10-25

Это перенос в настоящее FastAPI-приложение, а не только `interaction-lab`.
Сервер проверки: `http://127.0.0.1:8397/`, отдельный каталог
`.state/redesign-preview`, случайный операторский пароль. Публичного deploy нет.

## Реализовано

- Страницы `/`, `/login`, `/customers`, `/customers/{id}`, `/settings`, `/lab`
  используют общий React/Vite build `web/assets/interface/` и утверждённые токены.
- Сохранены существующие ES-контроллеры, API, фильтры, сортировка, правила ревизий,
  If-Match, подтверждение импорта, CSRF, обычная авторизация и OIDC.
- Оригинальные FaultyTerminal, Liquid Glass, Magic UI CTA, Blur Text, AnimatedContent
  и File Upload подключены из неизменённых vendor-снимков. ReUI CustomBar адаптирован
  к реальным API-интервалам; исходный фиолетовый цвет, узкие столбцы и раскрытие
  сохранены, добавлены второй ряд данных и доступные кнопки значений.
- Главная содержит композицию с исходными колоннами и описание реальных возможностей.
- Демо-вход создаёт отдельную временную SQLite-песочницу на сессию. Внутри можно
  менять модель и импортировать снимок. Данные оператора не копируются и не меняются.
- Мобильный рейтинг представлен карточками; меню раскрывается кнопкой, рабочие
  контролы имеют радиус 8 px и высоту не меньше 48 px.

## Браузерная проверка до разрыва сессии

Настоящий встроенный Chromium, а не API-клиент и не образец.

- PASS: главная с оригинальным глифовым фоном, исходным ассетом колонн, стеклом и CTA.
- PASS: переход на `/login`, кнопка демо открывает настоящий рейтинг из 10 клиентов.
- PASS на фактической ширине 360 CSS px: меню, Escape с возвратом фокуса, поиск
  без совпадений, сброс фильтров, карточки рейтинга, открытие клиента с данными API.
- PASS на 360 px: модель и сохранение горизонта 17 дней, версия настроек стала 2;
  лаборатория загрузилась с Geist и без горизонтального скролла.
- В исходном прогоне проверены ширины 320/360/768/1440. Найдено выступание главной
  на планшете; исправлено `overflow: clip` у художественной композиции. Поздний
  прогон показал отсутствие overflow на фактических ширинах 267/300/640/1200;
  override начал расходиться с фактическим CSS viewport, поэтому этот прогон
  не выдаётся за точную повторную проверку 320/360/768/1440.

После продолжения встроенный browser MCP перестал отвечать: inventory, создание
вкладки и выбор существующего браузера завершались timeout. Повторная визуальная
проверка последних правок (плавное раскрытие графика, размер BlurText, видимый
фокус мобильных заголовков сортировки и итоговая планшетная главная) НЕ выполнена.
Скриншоты были видны в инструменте до разрыва, но не сохранены как файлы; новый
снимок не подменяется изображением прежнего specimen. Открытие локального сайта
через `open_in_codex` поставлено в очередь для текущего чата.

Не выполнены: физические Android/iOS, Safari/Firefox, системные reduced motion /
forced colors / reduced transparency, измерение слабого GPU, итоговый browser
импорт, полный OIDC E2E, Docker/CI, публичный HTTPS и deploy. Обработчики reduced
motion, hidden tab, native file fallback и таблица значений предусмотрены кодом;
это не выдаётся за браузерную проверку этих режимов.

Никакие staging/commit/push/deploy этим переносом не выполнялись. В общем checkout
есть предсуществующие и параллельные изменения; текущий index не является составом
этого дизайн-среза. Не коммитить его целиком.
