# PP Neue Machina Inktrap

Единственный подключённый шрифт проекта по прямому выбору пользователя от 2026-10-22. Один variable-файл содержит веса 100–900; интерфейс использует 400/500, SVG-wordmark — контуры веса 600.

Источник — файл, используемый на [официальной странице Neue Machina Inktrap](https://pangrampangram.com/products/neue-machina). Точный URL и SHA-256 записаны в `sources.json`. Дата получения: 2026-10-22. Файл сохранён без модификации, конвертации или subsetting. URL заканчивается на `.woff`, но заголовок файла `wOF2`; локальное расширение исправлено на `.woff2`.

Pangram Pangram сохраняет авторские права; это не OFL. [Официальный FAQ](https://pangrampangram.com/pages/faq#free-fonts-and-personal-use) разрешает личную пробную работу, в том числе тестирование в dev-средах. Текущая подготовка — локальный дизайн-стенд. Коммерческая лицензия не приобреталась, публичная публикация файла в рамках этой задачи не выполнялась. Перед коммерческим использованием требуется соответствующее разрешение правообладателя.

`scripts/prepare-design-fonts.py` проверяет SHA-256 и cmap всех русских букв в обоих регистрах, включая Ё/ё, копирует файл и пересоздаёт оба wordmark. Файлы прежнего JetBrains Mono и его OFL удалены, поскольку сайт больше их не использует.
