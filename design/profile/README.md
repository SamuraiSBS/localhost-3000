# Профиль

Изолированная страница `/profile` для просмотра и правки тестового имени и почты, а также проверки формы смены пароля. Использует `design/tokens.css`, `design/foundation.css` и native HTML/CSS/ES modules.

Локальный запуск из корня репозитория:

```powershell
python -m http.server 3300 --bind 127.0.0.1 --directory design
```

Откройте `http://127.0.0.1:3300/profile`. Статический сервер перенаправит путь на каталог страницы.

Имя и почта загружаются из `demo-profile.json`. Их правки меняют только текущий просмотр и сбрасываются после перезагрузки. Форма пароля проверяет заполненность полей и совпадение нового пароля; вводимые пароли очищаются после успешной проверки, не отправляются и не сохраняются. Реальная авторизация и хранение учётных данных не подключены. Страница не меняет временный probe или выбранный стек продукта.
