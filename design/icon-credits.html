Автор: HackerNoon. Pixel Icon Library.

SVG-иконки распространяются на условиях Creative Commons Attribution 4.0 согласно README проекта. Файлы сохранены без изменений; цвет в интерфейсе задаётся CSS-маской.

Используется вариант regular на исходной сетке 24×24. Зафиксированы исходный commit и SHA-256 в описании происхождения.
