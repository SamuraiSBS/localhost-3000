# Dashboard

Изолированная адаптивная страница `/dashboard` для подготовки до получения ТЗ. Она использует `design/tokens.css`, `design/foundation.css` и локальный PP Neue Machina Inktrap; probe и продуктовый стек не меняются.

Запуск из корня проекта:

```powershell
python -m http.server 3300 --bind 127.0.0.1 --directory design
```

Откройте `http://127.0.0.1:3300/dashboard`. Статический сервер перенаправит адрес на папку страницы.

`components.js` содержит повторно используемые функции разметки боковой панели, мобильного Floating Dock, заголовка, карточек показателей, строк списка, общего состояния загрузки и ошибки. На широком экране Sidebar раскрывается при наведении и клавиатурном фокусе; на узком её навигацию заменяет Floating Dock внизу справа. Native-адаптация использует токены и локальные пиксельные иконки, не добавляя React, Tailwind или Motion. `demo-data.json` — единственный источник тестовых показателей и записей. Состояние загрузки возникает на время чтения этого файла; искусственной задержки нет. При пустых массивах показывается нейтральное пустое состояние, при ошибке загрузки — сообщение с повторной попыткой.

Sidebar содержит только текущую страницу; будущие пункты, подписи и данные следует определить после получения ТЗ. Страница остаётся отдельным образцом и сама по себе не выбирает сценарий конкурсного продукта.
