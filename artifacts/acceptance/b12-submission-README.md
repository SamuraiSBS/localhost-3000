# Локальный пакет B12

`b12-submission.zip` содержит принятый P0 source allowlist и P1 график. `b12-package-manifest.json` фиксирует каждый файл, SHA-256 и размер архива. Пакет не отправлялся и не публиковался.

После распаковки следовать корневому README: подготовить закрытую локальную конфигурацию через `scripts/configure_local.py`, затем запустить Compose. Указанные в README локальные credentials примеры не включены в ZIP. Для обычной демонстрации используется только синтетический `data/seed.json`.

На `/customers` доступны текущие уровни риска услуг, ближайшие продления высокого риска и условный сценарий нехватки средств без новых пополнений. Таблица значений открывается с клавиатуры. Истории удалений нет; график явно это объясняет. Правило/период/источник — `docs/p1-chart.md`; новая репетиция и границы — `docs/demo.md` и `artifacts/acceptance/b12-results.json`.

Шрифт PP Neue Machina Inktrap и исходные фотографии исключены по решению пользователя; в ZIP используются CSS Arial fallback и фон без исходного фото. Ожидаемый 404 для исключённого WOFF2 не означает поставку этого файла. Не включены исходный organizer dataset, root uploads, секреты, `.env`, `.state`, `.git`, pytest tests и runners (сохранена граница B11). Проверки checkout и ZIP различаются; ZIP integrity не заменяет runtime/browser/Docker проверку.

Пересборка: `python scripts/package_delivery.py`. Скрипт использует точный allowlist, не обходит весь checkout и не захватывает будущие P1 изменения автоматически. Локальные Docker/CI/public deployment новой версии должны иметь отдельные доказательства; исторические B10/B11 результаты не являются текущей B12 приёмкой.
