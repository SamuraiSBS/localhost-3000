# Решения

## 2026-10-22 — Подготовка до ТЗ

- Не придумывать продукт и не фиксировать стек. Probe на Python stdlib нужен только для инфраструктуры.
- Репозиторий приватный; видимость не менять.
- Пользователь выбрал будущую VM в Яндекс Облаке и домен `localhost-3000.ru`. VM пока нет; платные ресурсы не создавать.
- Пользователь подтвердил, что корневой домен свободен для проекта; отдельный поддомен не требуется. DNS менять после получения IP новой VM.
- Caddy отвечает за reverse proxy и автоматическое HTTPS после готовности DNS. Сертификаты сохраняются в томе.
- CI и CD разделены. CD принимает артефакт только успешного CI push `main` из этого репозитория; сторонние PR не получают deploy-секреты.
- Сборка маркируется commit SHA; деплой принимает только image digest. GITHUB_TOKEN используется на время workflow, SSH deploy key ограничивается отдельной VM. Docker group даёт фактические root-права, поэтому VM должна быть выделена этому проекту.
- Откат возвращает образ и Compose/Caddy предыдущего релиза. Это не zero-downtime: возможна короткая пауза при пересоздании контейнеров. Миграции/данные потребуют отдельной стратегии после ТЗ.

## 2026-10-22 — Digital Ruins / Lost Signal

- По пользовательскому brief закреплена независимая визуальная система до ТЗ: три повреждённые колонны, fine monochrome dithering, lowercase `localhost3000`, Terminal Bar, редкое Prism Glass. Подробности — `docs/design/README.md`; микроподписи и фиктивные статусы запрещены.
- Подготовка визуальной основы дополняет инфраструктуру; предметный продукт и стек не выбираются. Допустимость использования заранее подготовленного CSS/ассетов проверить по будущему регламенту.
- Единственный исполняемый источник токенов — `design/tokens.css`, простая основа на scoped CSS/native HTML. Нет новых npm/pip runtime-зависимостей. Отдельный локальный образец не меняет probe/Docker/CI и не публикуется автоматически.
- Для статичных колонн предпочтительна offline-подготовка с Pillow/Floyd–Steinberg и сравнением blue noise. Для Prism сначала изолированный SVG displacement прототип с непрозрачным fallback и browser QA; тяжёлый WebGL/Three.js только под обоснованную задачу.
- IBM Plex Mono и Onest сохранены как выбранная типографическая пара; кириллица/веса/OFL проверены по официальным метаданным, сами файлы не включены. Финальная графика, художественный wordmark, Prism и favicon не объявляются готовыми.

## 2026-10-22 — Реализация визуальной основы по продолжению пользователя

- Пользователь поручил реализовать оставшиеся пункты. В `design/` добавлены настоящая художественная сцена, две outlined SVG-версии wordmark, локальные WOFF2 с OFL и вход в нейтральную оболочку. Продуктовые разделы/данные не придумываются; probe и его Docker-контракт сохранены.
- Колонны созданы встроенным ImageGen. Дизеринг присутствует в исходнике; Sharp выполняет только экспорт/адаптивное уменьшение. Основной WebP пиксельно совпадает с PNG, мобильный весит около 303 KB; полный lossless 1.23 MB сохранён ради качества мелких точек. Промпт, происхождение и SHA-256 находятся рядом с ассетом.
- Prism Glass использует маленький собственный WebGL 1 sampler над этой графикой. Это избегает зависимости от несовместимого SVG backdrop refraction и не требует Three.js/захвата DOM. Статическая отрисовка, DPR cap 1.5, low-power; text scrim и непрозрачный fallback сохраняют доступность.
- Build tools FontTools/Sharp и тестовый Playwright отделены от runtime; локальные инструменты/браузеры в `.state`. `scripts/check.py` дополнен offline-проверкой ссылок, токенов, хешей, WOFF2 и бюджета ассетов, без сторонних Python-пакетов в CI.
- Для фиксации дизайна создан отдельный managed worktree. В коммит/PR входят только просмотренные файлы дизайна и его проверок; параллельные изменения challenge/deployment/infrastructure не включаются. Слияние в main и публичный deployment не входят в эту задачу.

## 2026-10-22 — Консольная типографика и пересмотр стекла

- Пользователь отверг первоначальные шрифты и попросил полностью консольную типографику. JetBrains Mono заменяет IBM Plex Mono / Onest во всём интерфейсе; веса 400/500, wordmark 600. Один локальный variable WOFF2 с полной кириллицей весит 71736 bytes. Ранние записи выше описывают историю решения.
- Заголовки уменьшены, логотип пересобран с небольшими локальными повреждениями. Стекло получает преломление у скруглённого края, слабую дисперсию и нейтральный направленный блик; постоянная радужная рамка и прямоугольная чёрная плашка удалены. Читаемость обеспечивает мягкая локальная маска внутри shader.
- Новая версия прошла 26 изолированных browser cases в Edge, Firefox и WebKit. Это проверка визуальной основы, а не утверждение пользователем или готовность конкурсного продукта.
