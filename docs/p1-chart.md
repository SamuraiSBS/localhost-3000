# График услуг и условных непродлений B12

На `/customers` один нативный график SVG/HTML показывает текущие уровни риска услуг и ближайшие продления услуг высокого риска. Под ним доступна та же информация в раскрываемой таблице. Все подписи — HTML-текст от 16 CSS px; SVG содержит только полосы, поэтому масштабирование графики не уменьшает подписи. Новых runtime dependencies нет.

## Происхождение и границы

Защищённый `GET /api/v1/analytics/churn-chart` один раз получает опубликованный immutable `Evaluation`. В нём зафиксированы `snapshot_json`, результаты service-level scoring, `evaluated_at`, модель, горизонт и revisions данных/настроек/анализа. Новый endpoint не пересчитывает score и не читает изменяемый источник отдельно. Он не меняет обязательные P0 endpoints.

Текущие уровни риска считают возобновляемые услуги `active/suspended/prolong_wait` по их уже рассчитанному `risk_level`, включая услуги за горизонтом. Последние отдельно указаны в подписи и не попадают в ряд ближайших продлений. `blocked/deleted` исключены из оцениваемого ряда; их текущие количества названы отдельно.

История удалений явно недоступна: источник не содержит дат событий. Поле `expiresAt` — срок услуги, а не дата её удаления. Текущий `deleted` не превращается в историческую точку. График не считает ушедших клиентов и не восстанавливает историю по транзакциям.

## Условный сценарий

Сплошная полоса показывает **число текущих услуг высокого риска** с ближайшим сроком в горизонте. Контурная полоса показывает подмножество: высокий риск и `funding_gap_cents > 0` из той же оценки. Допущение: до продления новых средств не поступит. Это условный сценарий возможных непродлений, не вероятность, не статистический прогноз и не число реальных отказов. Никакого `score / 100` для вычисления количества нет.

Модель уже распределила доступные средства один раз по `(expiresAt, id)`. График использует эти service-level gaps; одни деньги повторно не расходуются. Порог высокого риска берётся из зафиксированной модели. Изменение порога/весов/источника меняет ряды через новый Evaluation.

Каждая услуга учитывается один раз. Просроченные сроки `< as_of` показаны отдельной корзиной текущих обязательств; это не прошлые события ухода. Будущие интервалы: `[as_of, as_of + min(7,H)]`, затем `(предыдущая граница, as_of + min(14,H)]`, затем до `as_of + H` включительно. Повторяющиеся границы при коротком горизонте удалены. Подписи обозначают сутки от точного UTC-времени расчёта, а не календарные даты/полночь. Одно ближайшее продление не является всеми платежами за период.

## Обновление и отказ

Рейтинг и сводка сохраняют согласование по revisions. Перед публикацией графика проверяются те же `analysis_revision`, `data_revision`, `settings_revision`, `model_version`. Несовпадение/ошибка endpoint не блокирует обязательный рейтинг: старый график сохраняет свою дату и получает явную пометку, что он может отличаться от обновлённого рейтинга. При восстановлении следующая успешная попытка возвращает согласованный график. Неизменившийся график не перестраивается при polling. При 401/logout/pagehide общий `clearSession()` очищает также график.

## Выбор реализации

Проверенные родителем реестры не дали подходящего нативного компонента: shadcn Chart требует React/Recharts/lucide, несовместимых с утверждённым стеком; доступная metadata 21st Bar Chart не даёт бесплатного исходника. Источники платных компонентов не получались и не заимствовались. Собственные простые SVG-полосы используют существующие токены и не запускают animation loop. Палитра монохромная; факт и сценарий отличаются заливкой/контуром и текстом.

Проверки текущей версии и ограничения среды записаны в `artifacts/acceptance/b12-results.json`; исторические B10/B11 evidence относятся к прежним версиям. Локальная проверка не означает CI или публичный deploy.
