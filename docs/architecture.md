# Архитектура

Архитектура конкурсного продукта и стек пока не выбраны.

Временный стенд: браузер → Caddy → Python HTTP probe. На VPS контейнер приложения не публикует свой порт; proxy публикует 80/443. Постоянные тома Caddy сохраняют сертификаты. Базы данных пока нет: необходимость определяется ТЗ.

После выбора MVP описать границы компонентов, контракт API, модель данных, внешние зависимости, обработку ошибок, секреты и минимальную схему развёртывания. Выбирать простое решение с работающим основным сценарием.
