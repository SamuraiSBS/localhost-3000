# Демо для проверяющего

## Запуск

Запустите приложение по шагам из [README](../README.md), затем откройте `/login` и нажмите **«Зайти на демо»**. Вводить логин или пароль для демо не нужно.

Для каждого входа создаётся отдельная временная песочница с учебными данными. Изменения в демо не затрагивают учётную запись оператора. По истечении срока сессии начните демо заново.

## Основной сценарий

1. На странице клиентов найдите запись, измените фильтр или сортировку.
2. Откройте карточку клиента и посмотрите признаки, ближайшее продление, доступные средства и сумму под риском.
3. Измените коэффициент модели и сравните обновлённый рейтинг.
4. Откройте Decision Lab, измените параметры сценария и сравните расчёт до и после. Preview не сохраняет настройки рабочей модели.
5. Посмотрите чувствительность результата, очередь действий и календарь продлений.
6. Запустите solver с ограничениями и изучите предложенное действие. Сам расчёт не применяет его к данным.
7. Откройте preview импорта синтетического снимка, проверьте различия и подтвердите замену только внутри демо-песочницы.
8. Экспортируйте кейс и запустите replay, чтобы сравнить сохранённый результат с повторным расчётом.

## Как читать результат

Score — объяснимый индекс внимания, а не вероятность оттока. Сумма под риском — сценарная оценка, не подтверждённые потери. Неизвестные исходные значения показаны отдельно и не считаются нулевыми.
