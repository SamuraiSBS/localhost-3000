# Контракты компонентов

Компоненты независимы от будущей предметной области. Наличие контракта не означает готовую реализацию. Текущая [CSS-основа](../../design/foundation.css) реализует только простые элементы, перечисленные в [руководстве](IMPLEMENTATION_GUIDE.md).

| Компонент | Визуальный контракт | Поведение и доступность |
|---|---|---|
| Terminal Bar | Верхняя горизонтальная плоская панель, почти чёрный фон, тонкая линия, PP Neue Machina Inktrap | Семантический header/nav, понятные названия, `aria-current`; реальные пункты только после ТЗ. На mobile перенос/раскрытие, клавиатура и возврат фокуса. Не сайдбар и не плавающее стекло |
| Sidebar (изолированное исключение) | Плоская монохромная панель по [Aceternity UI Sidebar](https://ui.aceternity.com/components/sidebar); компактная ширина раскрывается без сдвига основной области | На широком экране — hover и клавиатурный фокус. Только для отдельной заготовки Dashboard; на узком экране используется Floating Dock. Не становится общей навигацией будущего продукта |
| Floating Dock (изолированное исключение) | Мобильный вариант [Aceternity UI Floating Dock](https://ui.aceternity.com/components/floating-dock), закреплённый у нижнего края; плоские монохромные поверхности и локальные пиксельные иконки | Нативная кнопка `aria-expanded` раскрывает подписанные ссылки вверх. Меню закрывается кнопкой, Escape или внешним нажатием; фокус и пункты доступны с клавиатуры. Только мобильная навигация отдельной заготовки Dashboard |
| Button | Монохром, прямоугольник, утверждённый радиус 2 px через `--radius-control`; главное действие со светлой заливкой, остальные контурные с различимой границей | Нативный button; для перехода — ссылка. 44×44 px, hover/focus/active/disabled/loading. Понятный глагол; только одно главное действие в группе |
| Input | Читаемый текст PP Neue Machina Inktrap, видимый label, контрастная граница | Label не заменять placeholder. Связанные подсказка/ошибка, корректный input type/autocomplete; invalid и disabled. Не блокировать вставку |
| Select | Та же геометрия и размеры, заметный текущий вариант | Предпочтительно native select; кастомный только при реальной необходимости, с клавиатурой, выбранным состоянием и доступным именем |
| Dialog | Плавающая панель, максимум умеренное скругление; Prism только после приёмки материала | Native dialog/проверенная реализация, доступное имя, focus trap, Escape, видимая кнопка закрытия, возврат фокуса. Содержимое не искажается оптическим слоем |
| Prism Glass Panel | Почти бесцветная прозрачная поверхность, локальное искажение подложки и тонкий спектральный край | Декоративный слой исключён из accessibility tree и событий. Читаемая подложка под текстом; непрозрачный fallback равноправен по функциям |
| Command Palette | Специальный диалог поиска доступных действий, не декоративный терминал | Создавать, когда существуют реальные команды. Combobox/listbox, стрелки/Enter/Escape, пустой результат, понятная подсказка shortcut. Shortcut не единственный путь открытия |
| Content Panel | Плоская поверхность, строгая иерархия, минимум границ | Семантические section/table/list по содержимому. Не вкладывать карточки в карточки. Длинные данные не ломают экран |
| Loading State | Спокойное изменение или текст о фактическом действии | `aria-busy`, умеренные объявления через live region; нет фиктивных процентов и искусственных задержек. При reduced motion остаётся текст |
| Empty State | Кратко объясняет отсутствие данных и следующий шаг, если он существует | Отличать отсутствие данных, результаты фильтра и отсутствие прав. Не придумывать данные или случайные CTA |
| Error State | Ясная причина и возможный способ исправления | Не только цвет. Для поля — связь с контролом; для сбоя — сохранять введённые данные, показывать повтор только если он безопасен |
| Error Page | Одна центрированная композиция с кодом HTTP (если он есть), коротким заголовком, пояснением и нужным действием | Один общий шаблон для 404, 403, 500 и потери связи. Повтор доступен для 500 и сетевого сбоя; возврат на главную — всегда. Статическая разметка работает без JavaScript |

## Границы нынешней реализации

Правила компоновки: длинные абзацы слева внутри центрированного блока; формы по центру, подписи и вводимый текст слева. Группы кнопок центрированы в ряд на широком экране и располагаются друг под другом на телефоне. Не допускать переполнения; главные мобильные действия во всю доступную ширину контейнера. Эти правила не означают завершённую перевёрстку всех существующих образцов.

Утверждены дополнительные контракты: checkbox квадратный, радиус 2 px, в выбранном состоянии светлая заливка и тёмная пиксельная галочка; tooltip непрозрачный тёмный, рамка 1 px, радиус 2 px, без стекла, доступен при hover и клавиатурном фокусе; разделители серые 1 px только между смысловыми блоками. Чекбокс сохраняет native-семантику и связанную подпись. Чекбокс и tooltip включены в `preview.html#states` и проверяются `scripts/test-components.cjs`.

Последнее уточнение: disabled-кнопки слегка красные, без обязательной причины рядом; это утверждённое семантическое исключение из монохрома. Нативное недоступное состояние сохраняется. Loading — текст действия без спиннера, с сохранением размера кнопки. Открытие dialog — проявление 150 ms, reduced motion — мгновенно. CSS disabled и открытия реализован в основе; настоящие async-сценарии ожидают ТЗ.

Утверждены постоянное подчёркивание текстовых ссылок, светлый клавиатурный outline 2 px с отступом 4 px и шкала отступов 4/8/12/16/24/32/48/64/96 px. Ошибки полей монохромны: пиксельная иконка, заметная рамка и связанное с полем пояснение снизу. Иконка не заменяет текст ошибки. В образец включены рамка, связанный текст и пиксельная иконка ошибки.

Подтверждены радиусы: стеклянные кнопки 2 px, плавающие стеклянные панели 12 px. Иконки HackerNoon: regular в обычном состоянии, solid в выбранном; выбранное состояние также доступно через семантику контрола. Набор подключаемых SVG расширяется только по мере появления реальных элементов.

Уточнения пользователя от 2026-10-22: карточки плоские, тёмно-серые, с прямыми углами и без теней. Нажатие кнопок меняет яркость мгновенно, без изменения геометрии. Иконки — локальные SVG из HackerNoon Pixel Icon Library, не набор тонких контурных значков. Для стекла ориентир размещения — Hero Section Aceternity: отдельная плавающая панель, плашка и вторичное действие поверх графики. `liquid-glass.html` показывает этот принцип, не задавая продуктовую навигацию. Кнопки сохраняют радиус 2 px; Terminal Bar рабочей области остаётся плоской.

`foundation.css` содержит токенизированные кнопки, поля, select, плоскую панель, Terminal Bar и непрозрачный dialog fallback. `preview.html` проверяет их на нейтральных примерах; его ссылки «Основа» и «Элементы» относятся к образцу, не задают продуктовую навигацию. `index.html`/`scene.js` реализуют главную сцену, вход и нейтральную оболочку; `prism.js` — статическую рефракцию собственной графики внутри демонстрационного dialog. Произвольный живой DOM этим материалом не захватывается.

Command Palette, состояния сетевых запросов и продуктовые таблицы будут реализованы только при необходимости. Возврат фокуса dialog задаётся явно: различия нативного восстановления фокуса в WebKit не должны менять контракт.

Новые компоненты получают состояния до встраивания в пользовательский сценарий. Не создавать компоненты «личный кабинет», «AI аналитика», «бизнес-метрики» или другие модули до ТЗ. Не добавлять decorative captions, 10–13 px текст и фиктивные статусы.
