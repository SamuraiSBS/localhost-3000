# Компоненты интерфейса

## Навигация и действия

- Верхняя Terminal Bar — плоская горизонтальная навигация с понятными названиями и семантическим текущим пунктом.
- Переходы оформляются ссылками, действия — нативными кнопками. У каждого элемента есть заметный клавиатурный фокус и область нажатия не менее 44×44 CSS px.
- На узком экране важные пункты и действия остаются доступны без горизонтальной прокрутки.

## Данные и формы

- Таблицы используют заголовки столбцов, осмысленный порядок, читаемые значения и доступные сортировку и фильтры.
- Формы имеют видимые подписи, подходящие типы полей и связанные с ними ошибки. Подсказка не заменяет подпись; вставку текста не блокировать.
- Графики сопровождаются текстовым объяснением или доступным табличным представлением. Цвет не служит единственным способом передать значение.

## Состояния

- Загрузка сообщает о фактическом действии и не создаёт искусственную задержку.
- Пустое состояние объясняет отсутствие данных и предлагает следующий шаг, если он есть.
- Ошибка показывает причину и безопасный способ продолжить, сохраняя введённые пользователем данные.
- Недоступное состояние использует нативную семантику. Для диалогов нужны доступное имя, Escape и предсказуемый возврат фокуса.

Плоские панели и общие стили контролов используют значения из `design/tokens.css` и базовые правила из `design/foundation.css`.
