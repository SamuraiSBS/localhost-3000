# Контракты компонентов

Компоненты независимы от будущей предметной области. Наличие контракта не означает готовую реализацию. Текущая [CSS-основа](../../design/foundation.css) реализует только простые элементы, перечисленные в [руководстве](IMPLEMENTATION_GUIDE.md).

| Компонент | Визуальный контракт | Поведение и доступность |
|---|---|---|
| Terminal Bar | Верхняя горизонтальная плоская панель, почти чёрный фон, тонкая линия, JetBrains Mono | Семантический header/nav, понятные названия, `aria-current`; реальные пункты только после ТЗ. На mobile перенос/раскрытие, клавиатура и возврат фокуса. Не сайдбар и не плавающее стекло |
| Button | Монохром, прямоугольник, малый радиус; primary светлая, secondary с различимой границей | Нативный button; для перехода — ссылка. 44×44 px, hover/focus/active/disabled/loading. Понятный глагол; только одно главное действие в группе |
| Input | Читаемый текст JetBrains Mono, видимый label, контрастная граница | Label не заменять placeholder. Связанные подсказка/ошибка, корректный input type/autocomplete; invalid и disabled. Не блокировать вставку |
| Select | Та же геометрия и размеры, заметный текущий вариант | Предпочтительно native select; кастомный только при реальной необходимости, с клавиатурой, выбранным состоянием и доступным именем |
| Dialog | Плавающая панель, максимум умеренное скругление; Prism только после приёмки материала | Native dialog/проверенная реализация, доступное имя, focus trap, Escape, видимая кнопка закрытия, возврат фокуса. Содержимое не искажается оптическим слоем |
| Prism Glass Panel | Почти бесцветная прозрачная поверхность, локальное искажение подложки и тонкий спектральный край | Декоративный слой исключён из accessibility tree и событий. Читаемая подложка под текстом; непрозрачный fallback равноправен по функциям |
| Command Palette | Специальный диалог поиска доступных действий, не декоративный терминал | Создавать, когда существуют реальные команды. Combobox/listbox, стрелки/Enter/Escape, пустой результат, понятная подсказка shortcut. Shortcut не единственный путь открытия |
| Content Panel | Плоская поверхность, строгая иерархия, минимум границ | Семантические section/table/list по содержимому. Не вкладывать карточки в карточки. Длинные данные не ломают экран |
| Loading State | Спокойное изменение или текст о фактическом действии | `aria-busy`, умеренные объявления через live region; нет фиктивных процентов и искусственных задержек. При reduced motion остаётся текст |
| Empty State | Кратко объясняет отсутствие данных и следующий шаг, если он существует | Отличать отсутствие данных, результаты фильтра и отсутствие прав. Не придумывать данные или случайные CTA |
| Error State | Ясная причина и возможный способ исправления | Не только цвет. Для поля — связь с контролом; для сбоя — сохранять введённые данные, показывать повтор только если он безопасен |

## Границы нынешней реализации

`foundation.css` содержит токенизированные кнопки, поля, select, плоскую панель, Terminal Bar и непрозрачный dialog fallback. `preview.html` проверяет их на нейтральных примерах; его ссылки «Основа» и «Элементы» относятся к образцу, не задают продуктовую навигацию. `index.html`/`scene.js` реализуют главную сцену, вход и нейтральную оболочку; `prism.js` — статическую рефракцию собственной графики внутри демонстрационного dialog. Произвольный живой DOM этим материалом не захватывается.

Command Palette, состояния сетевых запросов и продуктовые таблицы будут реализованы только при необходимости. Возврат фокуса dialog задаётся явно: различия нативного восстановления фокуса в WebKit не должны менять контракт.

Новые компоненты получают состояния до встраивания в пользовательский сценарий. Не создавать компоненты «личный кабинет», «AI аналитика», «бизнес-метрики» или другие модули до ТЗ. Не добавлять decorative captions, 10–13 px текст и фиктивные статусы.
