# Эффекты

Эффекты поддерживают содержание страницы и не должны мешать чтению, вводу или навигации. Общие параметры берутся из `design/tokens.css`.

## Фон и графика

Общий монохромный Terminal Field использует локальные WebGL2-шейдеры. Слой декоративный: он исключён из accessibility tree и не перехватывает указатель. При скрытой вкладке анимация останавливается; при `prefers-reduced-motion` остаётся неподвижное изображение. Если WebGL2 недоступен, содержимое страницы остаётся читаемым на тёмном фоне.

Колонны главной сцены и локальный шрифт загружаются из `design/assets`. Не добавлять сетевые runtime-зависимости для декоративных эффектов.

## Дизеринг и оптика

Монохромный Bayer-дизеринг предназначен для изображений. Он не должен ухудшать читаемость текста или заменять исходный ассет. Prism Glass допустим только для оправданного плавающего элемента; у эффекта должен быть читаемый fallback без размытия и оптического искажения.

## Доступность и производительность

Использовать короткие переходы только для реальных изменений состояния. Фокус должен оставаться видимым, содержимое доступным без анимации, а reduced motion — убирать движение. Ограничивать непрерывную перерисовку и проверять влияние графики на узких экранах.
