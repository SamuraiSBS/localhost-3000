# Детали нового интерфейса — 2026-10-24

Статус: **интерактивное предложение для согласования**, не завершённый редизайн
продуктовых маршрутов. Образец: `design/interaction-lab/index.html`, исходники:
`frontend/`. Он не обращается к API, не сохраняет настройки, не читает содержимое
выбранных файлов и не выполняет импорт. Все числа и клиенты явно демонстрационные.

## Прямые решения пользователя в текущем диалоге

- Разрешено пересмотреть прежнюю композицию, шрифт и визуальную основу.
- Нужны заметные анимации на всех страницах.
- Выбранные примеры нужно переносить с исходными цветами, шрифтом, размерами и
  поведением. Приблизительную реализацию нельзя выдавать за исходный эффект.
- Подборка принята с заменой основного фона на **React Bits FaultyTerminal**.
- Отдельно согласованы **React/Vite для интерфейса при сохранении FastAPI и API**.
- Дополнительно требуется проработать геометрию и состояния всех элементов.
- В образце пользователь выбрал **радиус 8 px для рабочих кнопок**. Оригинальная
  кнопка Magic UI остаётся отдельной капсулой.

Эти решения заменяют противоречащие им прежние пользовательские ограничения для
нового дизайна. Нынешний образец изолирован. Старые продуктовые страницы и их
обработчики не заменены. `docs/decisions.md` занят активным B14 claim, поэтому
текущая запись решения сохранена в этом отдельном документе и `.21st/design.json`.

## Предложение по элементам

| Элемент | Геометрия и состояния | Движение и взаимодействие |
|---|---|---|
| Фон | Исходный FaultyTerminal, без переписывания шейдеров | Phosphor с текущего демо; отдельное сравнение с прежним монохромом. Ручная пауза, hidden tab, reduced motion |
| Основная кнопка из каталога | Оригинальная капсула Magic UI | Расширение точки, смена текста, появление стрелки; адаптер фокуса сохраняет рисунок |
| Рабочая основная кнопка | Предложение: высота 48 px, радиус 8 px | Заливка входит снизу за 240 ms, стрелка смещается на 4 px; короткое нажатие на 1 px |
| Варианты формы | 2 px / 8 px / капсула | В образце есть переключатель; пользователь выбрал 8 px |
| Вторичная кнопка | Прозрачная поверхность, заметная граница | Подсветка поверхности и границы; геометрия сохраняется |
| Текстовая кнопка | Без постоянной рамки, область нажатия от 44 px | Подсветка при hover/focus, необязательная стрелка |
| Опасное действие | Текст, контрастная граница и явный глагол | Подтверждение в диалоге; одно цветовое отличие не заменяет объяснение |
| Недоступное действие | Native disabled | Не реагирует на hover/click; запретный курсор |
| Выполняемое действие | Сохраняется место под подпись | Текст действия и спокойная точка; в образце задержка обозначена как демонстрационная |
| Завершённое действие | Галочка и текст | Уведомление с кнопкой закрытия; `aria-live`, без захвата фокуса |
| Кнопка-иконка | 48×48 px, доступное имя | Та же поверхность и фокус, что у остальных кнопок |
| Поле | Видимый label, радиус 8 px, высота 52 px | Различимый контур фокуса, hover границы, читаемый placeholder |
| Ошибка поля | Иконка, текст исправления и граница | `aria-invalid`, связанный текст, фокус первого неверного поля |
| Пароль | Кнопка внутри правого края поля | Показ/скрытие без потери текста; доступное имя и `aria-pressed` |
| Select | Нативный выбор, стиль остальных полей | Клавиатура и системное меню сохраняются |
| Checkbox | Квадрат, видимая галочка | Выбор связан с полной текстовой подписью |
| Switch | Дорожка и сдвигающийся бегунок | `role=switch`, состояние `aria-checked`, вся строка кликабельна |
| Диапазон | Ползунок и точное численное значение | Изменение видно сразу; управление стрелками |
| Вкладки | Нижняя линия активного пункта | Линия перемещается; стрелки, Home/End, связанный tabpanel |
| Таблица | Чёткие строки, числа выровнены, внутренняя прокрутка | Hover/focus-within строки, поиск, сортировка; перестановка строк через Motion |
| Пустой поиск | Текст причины и способ изменить запрос | Не подставлять случайные строки |
| График | Снимок исходного ReUI Animated Bar Chart с 21st | Оригинальные фиолетовые столбцы, расширение и подпись при наведении |
| Раскрытие | Native details/summary | Поворот плюса, текст без дополнительной рамки |
| Tooltip | Непрозрачный фон, читаемый текст | Hover и фокус, Escape, отсутствие перехвата указателя |
| Dialog | Native dialog, радиус 12 px | Проявление и подъём 12 px, Escape, закрытие/возврат фокуса |
| Liquid Glass | Исходный SVG displacement из Aceternity | Refraction в Chromium; исходный матовый/непрозрачный fallback |
| Заголовки | Исходный React Bits Blur Text | Проявление из расфокуса, возможность повторить в образце |
| Появление блоков | Исходный Animated Content | Последовательное появление, небольшой сдвиг и расфокус |
| Импорт | Исходный Aceternity File Upload | Поднимающаяся плитка и карточка выбранного файла; клавиатурный выбор добавлен отдельно |
| Шрифт | Geist Sans и Geist Mono, локальные WOFF2 из Fontsource | Кириллица в отдельных локальных subsets; исходные размеры компонентов не выдаются за новые правила всего сайта |

Авторские значения находятся в `[data-design-lab]` в `design/tokens.css`.
Существующие `:root` токены продукта не переопределены. Исходники из реестров лежат
в `frontend/src/vendor`; для них сохраняются тема и зависимости примера. Прямое
копирование CSS-токенов в независимую продуктовую тему не выполнялось.

## Источники и точность

- [FaultyTerminal](https://reactbits.dev/backgrounds/faulty-terminal)
- [Interactive Hover Button](https://magicui.design/docs/components/interactive-hover-button)
- [Blur Text](https://reactbits.dev/text-animations/blur-text)
- [Animated Content](https://reactbits.dev/animations/animated-content)
- [Liquid Glass](https://ui.aceternity.com/components/liquid-glass)
- [Animated Bar Chart](https://21st.dev/@sean0205/components/c-chart-11)
- [File Upload](https://ui.aceternity.com/components/file-upload)

JSON-снимки официальных реестров и SHA-256: `frontend/registry/manifest.json`.
`npm run check:sources` проверяет, что JSON и извлечённые vendor-файлы не изменены.
График `Chart21st.tsx` взят из полученного 21st MCP snapshot: прямой реестр ReUI
на момент получения уже содержит другой набор импортов. Registry snapshot также
сохранён; он не выдается за использованную версию графика.

Добавлены внешние адаптеры: общая тема, контейнеры, `cn`, Badge, подписи ARIA для
дублированного текста кнопок, CSS-реакция оригинальной кнопки на клавиатурный фокус.
У исходного графика есть hover-only взаимодействие и мелкие надписи, у загрузчика —
кликабельный div и скрытый input. Это ограничения исходников, а не пройденная
доступность. Для рабочего сайта нужны адаптеры с сохранением внешнего вида и
реальных контрактов API. Pixel-perfect приёмка всех сторонних демо не заявляется.

Phosphor: `#a7ef9e`, glyphs blocks, scale 1.5, digitSize 1.2, timeScale 0.5,
brightness 0.75, glow/persistence 0.5, scanlineIntensity 0.5, curvature 0.1,
mouseReact true, clickEffect glitch. Это значения просмотренного демо.
Изменены только внешние ограничения: DPR 1.5, фиксированный seed для
воспроизводимости, пауза/системный reduced motion. Монохромный вариант использует
параметры предыдущего проекта и подписан отдельно.

## Запуск и границы

```powershell
cd D:\localhost-3000\frontend
npm ci
npm run check:sources
npm run build
cd ..
.venv\Scripts\python.exe -m http.server 3387 --bind 127.0.0.1 --directory design
# http://127.0.0.1:3387/interaction-lab/
```

Vite очищает только свой сгенерированный каталог `design/interaction-lab`.
Публикация, Docker build, CI, продуктовый E2E и перенос на все страницы в этот
дизайн-образец не входят. Проверки текущего образца записаны в
`frontend/VERIFICATION.md`.
