# Проверка интерфейса

Перед выпуском изменений интерфейса проверьте применимые пункты и укажите, что именно было проверено.

- [ ] Сохранены идентичность Digital Ruins / Lost Signal и правила из [дизайн-системы](DESIGN_SYSTEM.md).
- [ ] Ключевой путь из [сценария демо](../demo.md) работает в браузере.
- [ ] Интерфейс проверен на узком и широком экране; нет непреднамеренной горизонтальной прокрутки.
- [ ] Все действия доступны с клавиатуры, фокус видим, подписи связаны с полями.
- [ ] Текст читаем при увеличении масштаба; полезные подписи не мельче 16 CSS px при стандартной базе.
- [ ] Состояния загрузки, пустых данных и ошибок сообщают о фактическом состоянии.
- [ ] Движение отключается при `prefers-reduced-motion`; без WebGL декоративный фон не скрывает содержимое.
- [ ] В локальных результатах отделены проверенные факты от непроверенных CI, Docker, VPS и публичного окружения.
