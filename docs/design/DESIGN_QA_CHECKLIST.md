## Идентичность

- [ ] Сохранён Digital Ruins / Lost Signal, 80% ретро / 20% современность; нет шаблонного SaaS/AI dashboard.
- [ ] Нет мелких декоративных подписей, псевдостатусов, координат, случайных индексов, номеров секций и микротекста над заголовками. Запрет относится к паттерну, а не только к примерам слов.
- [ ] Палитра берётся из токенов; фон без синего оттенка, около 95% монохрома, спектр редкий и оптический. Нет цветных CTA и обычных радужных заливок.
- [ ] Пустое пространство сохраняет роль в композиции; нет наполнения ради наполнения, сеток, частиц и тумана.
- [ ] На корневой главной три исходные колонны и временная точечная маска из `design/landing.js`; после входа Canvas удалён, без JS/reduced motion сразу доступен исходный рисунок.
- [ ] Заголовок `localhost3000` и ссылка-действие `ENTER SYSTEM` — HTML-текст, действие ведёт к входу.
- [ ] Liquid Glass остаётся локальным материалом оправданных поверхностей; обычное главное действие светлое, фокус и текст читаемы.
- [ ] На корневой главной нет внешней прокрутки; точки не мешают читать текст на узком и широком экранах.
- [ ] Нет самовольного разрушения, физики, постоянного glitch/RGB/дрожания; favicon не объявлен утверждённым.

## Компоненты и доступность

- [ ] Верхняя плоская Terminal Bar, реальные пункты из ТЗ и заметное активное состояние; нет сайдбара/стеклянной навигации по умолчанию.
- [ ] PP Neue Machina Inktrap загружен локально с записанным происхождением, кириллицей и нужными весами; единая типографика, размеры 32/24/16 и fallback проверены при блокировке загрузки. Отдельно проверить реальный шрифт кириллицы, а не только CSS font-family.
- [ ] Обычный текст, labels и placeholders не меньше 16 CSS px; браузерный размер не уменьшен, текст не спрятан низким контрастом.
- [ ] Контраст обычного текста ≥4.5:1, крупного ≥3:1, границ необходимых контролов/фокуса ≥3:1. На стекле проверены разные подложки.
- [ ] Контролы от 44×44 CSS px, видимый focus-visible, логичный Tab-порядок, Enter/Space и нужные стрелки; нет hover-only действий.
- [ ] Labels связаны с полями; ошибки объясняют исправление и связаны с `aria-describedby`. Selected/disabled/invalid/busy имеют семантику.
- [ ] Dialog/палитра имеют доступное имя, удерживают фокус, закрываются Escape/кнопкой и возвращают фокус открывшему контролу.
- [ ] Loading/empty/error честные, без фиктивных данных/метрик/процентов. Статус понятен без цвета.

## Адаптивность и эффекты

- [ ] Проверены 360, 768, 1440 CSS px, узкий 320 px и 200% масштаб: нет обрезанных заголовков/контролов/фокуса и горизонтального скролла всей страницы.
- [ ] Mobile перестраивает композицию, а не уменьшает всё вместе с текстом. Длинная кириллица и URL не ломают layout.
- [ ] Prism используется только для оправданной плавающей панели; текст и действия не преломляются. Blur отдельно не назван полноценным Prism Glass.
- [ ] Есть видимое смещение подложки линзой и тонкий спектральный край; проверены Chromium/Firefox/Safari, а не только `CSS.supports`.
- [ ] Непрозрачный fallback, forced colors и reduced transparency сохраняют функциональность. Неподдерживаемый shader/потеря контекста не оставляет пустоту.
- [ ] Reduced motion устраняет ожидания и движение. Без JS/анимации доступен основной контент; загрузка ассета не создаёт скачков.
- [ ] Статичная сцена не требует постоянного рендера; динамика останавливается в фоне. Размеры ассетов, шрифтов и frame time измерены на целевых устройствах.
