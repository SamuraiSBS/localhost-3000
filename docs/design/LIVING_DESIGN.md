# Живой Digital Ruins / Lost Signal

Пользователь утвердил таблицу элементов и анимационную часть 2026-10-24.
Главная возвращается к трём имеющимся колоннам; PP Neue Machina Inktrap,
почти чёрная палитра, иерархия 32/24/16 и плоская Terminal Bar сохраняются.

## Главная

`web/index.html` — продуктовый маршрут `/`; `design/index.html` — изолированный
вариант с относительным переходом к образцу входа. `landing.css` задаёт композицию,
`landing.js` проявляет исходную графику через исчезающую Bayer-маску и затем
проявляет заголовок и действие. Исходные изображения и provenance не изменяются.
Без JS исходное изображение и ссылка доступны сразу. После появления Canvas
удаляется: постоянного цикла перерисовки нет. Hidden tab/reduced motion отменяют
временный слой и возвращают изображение.

За композицией колонн на главной работает FaultyTerminal из исходного примера
React Bits. Он подключён ко всем продуктовым маршрутам: /, /login, /customers,
/customers/{customer_id} и /settings. В модуле design/terminal-field.js используются
исходные WebGL2-шейдеры, расчёт поля и свечение; жизненный цикл адаптирован к общей
HTML/ES modules-основе без React. Настройки совпадают с примером в предоставленном
пользователем файле и централизованы в design/tokens.css. Фон декоративный, не
содержит данных и не реагирует на указатель; скрытая вкладка останавливает кадры,
reduced motion показывает статичный кадр, forced colors скрывает canvas. Фото удалено
с фона входа, колонны остаются отдельной художественной композицией поверх эффекта.
Chroma Current сохранён как исторический файл без подключений к продуктовым маршрутам.

## Рабочие экраны

Все продуктовые страницы используют тот же низкоконтрастный монохромный фон.
Содержимое остаётся поверх него на штатных поверхностях и с исходным контрастом.

- Сводка — единая широкая поверхность; дополнительные расчётные сведения раскрываются.
- Таблица сохраняет обязательные поля, сортировки, поиск, фильтр, внутреннюю прокрутку
  и нормальные маршруты. Риск имеет текстовое значение и дополнительный монохромный знак.
- Страница клиента разделена на объяснение, деньги, услуги и транзакции; meter
  дополняет точный текстовый score. На телефоне секции складываются в одну колонку.
- Настройки используют две колонки признаков на широком экране. Импорт — отдельная
  область с native file input и drag/drop; файл не отправляется до отдельного подтверждения.
- Вход имеет архитектурную и формовую области. OIDC и password login сохраняют
  существующие обработчики. Регистрация остаётся визуальным образцом в `design/register.html`.

## Движение и графики

`motion.js` использует Web Animations API и IntersectionObserver. Контент по умолчанию
виден; временное начальное состояние существует только во время анимации.
Родственные элементы появляются короткой последовательностью; раскрытие деталей
сохраняет native details/summary. В поддерживающих браузерах обычная навигация получает
короткий CSS view transition. Неподдерживающий браузер делает обычный переход.

График использует реальные значения того же analysis revision: горизонтальные
полосы распределения и парные столбцы срока продления. Сплошная заливка означает
высокий риск, контур — условные непродления. Высота столбца меняется от предыдущего
согласованного значения; числа доступны без ожидания анимации. Подсказки открываются
мышью/фокусом/нажатием, закрываются Escape. Альтернативная таблица сохранена.
Пустые данные, неизвестный риск и отсутствие истории остаются явными состояниями.

Тайминги общего движения находятся в `design/tokens.css`. Reduced motion отменяет
анимацию, скрытие вкладки останавливает текущие эффекты. Мобильная навигация
открывается кнопкой «Меню», закрывается Escape/кликом снаружи; Escape возвращает фокус.

## Источники и реализация

Изучены 21st MCP Simple Header / Dithering / File Upload и shadcn MCP
`@react-bits/Dither-JS-CSS`, `@aceternity/liquid-glass`, `@shadcn/data-table-demo`.
Визуальные ориентиры: [Blur Text](https://reactbits.dev/text-animations/blur-text),
[Animated Content](https://reactbits.dev/animations/animated-content),
[Charts](https://ui.shadcn.com/docs/components/base/chart).
Фон использует предоставленный пользователем исходный FaultyTerminal-JS-CSS из
React Bits: сохранены его WebGL2-шейдеры и отрисовка, а React-оболочка заменена
mount-функцией в нативном ES-модуле. React dependency не добавлялась. Использованные
исходник и лицензия отмечены в THIRD_PARTY_NOTICES.md; параметры примера заданы в
tokens.css. Остальные новые эффекты используют существующие native-примитивы.
Выбор записан также в файле .21st/design.json.

Проверка, размеры viewport и ограничения фиксируются отдельно в `VERIFICATION.md`.
Прежние ZIP/приёмочные снимки не регенерируются: они относятся к прежней версии.
Allowlist упаковщика дополнен требуемыми motion/landing/living assets и `dither.js`,
который импортируется существующим login-модулем. Шрифт и пользовательское фото
не добавляются в пакет этим изменением.
