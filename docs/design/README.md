## Порядок чтения

[Карта дизайна](DESIGN_MAP.md) фиксирует ответы пользователя по отдельным элементам. Типографика и вариант Б утверждены; следующие параметры уточняются в диалоге.

Для новых фотографий сохраняется правило Aceternity Dither Shader: точка **1 CSS px**,
порог **0.50**. [Образец сравнения](../../design/dither.html) показывает
Bayer/duotone на Canvas 2D; фото больше не служит фоном продуктовой страницы входа.
С 2026-10-24 все продуктовые маршруты (/, /login, /customers,
/customers/{customer_id}, /settings) используют FaultyTerminal из предоставленного
пользователем источника React Bits. В общем модуле design/terminal-field.js сохранены
исходные WebGL2-шейдеры и логика свечения; React lifecycle заменён нативным
подключением в HTML, без перевода сайта на React. Настройки совпадают с Usage Example
в файле пользователя и централизованы в design/tokens.css. Главные колонны остаются
перед фоном. Старый Chroma Current сохранён изолированно.

Для жидкого стекла выбран [Aceternity Liquid Glass](../../design/liquid-glass.html) с пресетом Controls: circle / 50 / 20 / 60 / 4.8 / 0.05. Настройки заданы в токенах, из них генерируется React/DialKit-конфигурация; native-образец показывает оригинальный SVG-алгоритм и браузерные fallback. Прежний WebGL Prism остаётся ранним отдельным прототипом.

1. [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md) — фундамент и ограничения.
2. [VISUAL_IDENTITY.md](VISUAL_IDENTITY.md) — художественная сцена и логотип.
3. [COMPONENTS.md](COMPONENTS.md) — нужный компонент перед реализацией.
4. [EFFECTS.md](EFFECTS.md) — рецепт нужного эффекта.
5. [IMPLEMENTATION_GUIDE.md](IMPLEMENTATION_GUIDE.md) — фактический стек, инструменты и перенос.
6. [DESIGN_QA_CHECKLIST.md](DESIGN_QA_CHECKLIST.md) — перед сдачей изменения.

Числовые значения дизайн-системы править в [design/tokens.css](../../design/tokens.css);
конфигурация глифового фона также централизована в `--terminal-field-*`.
[design/foundation.css](../../design/foundation.css) — переносимая основа,
[design/preview.html](../../design/preview.html) — образец базовых элементов.
[design/index.html](../../design/index.html) — художественная сцена с колоннами,
общим фоном и нейтральной оболочкой без предметной логики.

## Что подготовлено

Правила идентичности, контракты компонентов, CSS-токены, простые доступные элементы,
локальный PP Neue Machina Inktrap и архитектурные ассеты. По последнему уточнению
пользователя шрифт един для всех элементов; утверждена иерархия Б — 32/24/16 px.
Происхождение шрифта и границы локального использования записаны рядом с файлом.
Главная сохраняет колонны, заголовок `localhost3000` и `ENTER SYSTEM` в DOM; общий
монохромный FaultyTerminal работает на продуктовых маршрутах и не отображает
содержимое приложения. Его WebGL2 canvas останавливается при скрытой вкладке; reduced
motion оставляет неподвижный кадр, forced colors отключает графический слой. Prism Glass реализован отдельным
WebGL-сэмплером над собственной архитектурной подложкой: линза, слабое разделение
каналов на контрастных краях, нейтральный блик, читаемый DOM-текст и непрозрачный
fallback. Дополнительно подготовлена изолированная страница
[Dashboard](../../design/dashboard/README.md) со сменяемыми демо-данными и
переиспользуемыми компонентами; она не задаёт продуктовые разделы.

Дизайн подключён к `AGENTS.md`, корневым `PRODUCT.md`/`DESIGN.md` и проектным навыкам разработки/приёмки. Исходники экспорта и тесты: [design/tooling/README.md](../../design/tooling/README.md). Статус и границы проверок: [VERIFICATION.md](VERIFICATION.md).

## Что остаётся за границами

Конкурсное приложение, его данные и навигация ждут ТЗ. Ссылка `CONNECT` открывает статичную форму входа; вход и регистрация пока не подключены к backend и не отправляют данные. Нейтральная оболочка по-прежнему доступна отдельно через `#workspace`. Favicon оставлен до отдельного решения о форме. Предыдущие ассеты проверены агентом в браузере; проверку новых страниц фиксировать отдельно от прежней. Реальный Safari, экранный диктор, физическое слабое устройство и настоящий toolbar zoom требуют отдельной среды; не подменять их результатами WebKit/CSS zoom/эмуляции.

Страницы ошибок в [design/errors/](../../design/errors/) — независимый статический образец общего шаблона, а не маршруты конкурсного приложения. Они сохраняют основную разметку без JavaScript и используют те же токены и кнопки.

Важнейший запрет: **никаких мелких декоративных подписей**, случайных статусов, индексов или псевдосистемных сообщений. Полезный текст — от 16 CSS px.
