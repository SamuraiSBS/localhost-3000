# Дизайн-система

Интерфейс использует визуальную идентичность **Digital Ruins / Lost Signal**: холодная уединённость, почти чёрная монохромная палитра и редкий мелкоточечный дизеринг.

Для страниц применяются общие токены из `design/tokens.css` и основа `design/foundation.css`. Основной локальный шрифт — PP Neue Machina Inktrap; сведения о происхождении ассетов и условиях использования — в [уведомлениях о сторонних материалах](THIRD_PARTY_NOTICES.md).

Ключевые правила и компоненты:

- [Визуальная идентичность](VISUAL_IDENTITY.md)
- [Токены и базовые компоненты](DESIGN_SYSTEM.md)
- [Компоненты интерфейса](COMPONENTS.md)
- [Эффекты и fallback](EFFECTS.md)
- [Руководство реализации](IMPLEMENTATION_GUIDE.md)
- [Чеклист доступности и адаптивности](DESIGN_QA_CHECKLIST.md)

Главная сцена и продуктовые экраны используют существующие локальные ресурсы из `design/assets`. Эффекты должны сохранять читаемость, клавиатурный фокус и поддержку reduced motion.
