# Дизайн localhost3000

Утверждённое направление — **Digital Ruins / Lost Signal**. Основание: пользовательский документ «промт дизайн.txt», применённый к проекту 2026-10-22. ТЗ хакатона пока неизвестно. Эти правила сохраняются после его получения; функциональность определяется отдельно.

## Порядок чтения

[Карта дизайна](DESIGN_MAP.md) фиксирует ответы пользователя по отдельным элементам. Типографика и вариант Б утверждены; следующие параметры уточняются в диалоге.

Для дизеринга пользователь выбрал Aceternity Dither Shader и утвердил размер точки **1 CSS px**, порог **0.50**. [Образец сравнения](../../design/dither.html) адаптирует его Bayer/duotone на Canvas 2D. Главная `/` и страницы авторизации используют предоставленный PNG с прозрачностью на чёрном фоне сайта; камень отображается белым. На ПК он целиком помещается без обрезки, на узком экране кадр заполняет область. Заголовок набран текстом `localhost3000`, действие — текстом `CONNECT`.

Для жидкого стекла выбран [Aceternity Liquid Glass](../../design/liquid-glass.html) с пресетом Controls: circle / 50 / 20 / 60 / 4.8 / 0.05. Настройки заданы в токенах, из них генерируется React/DialKit-конфигурация; native-образец показывает оригинальный SVG-алгоритм и браузерные fallback. Прежний WebGL Prism остаётся ранним отдельным прототипом.

1. [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md) — фундамент и ограничения.
2. [VISUAL_IDENTITY.md](VISUAL_IDENTITY.md) — художественная сцена и логотип.
3. [COMPONENTS.md](COMPONENTS.md) — нужный компонент перед реализацией.
4. [EFFECTS.md](EFFECTS.md) — рецепт нужного эффекта.
5. [IMPLEMENTATION_GUIDE.md](IMPLEMENTATION_GUIDE.md) — фактический стек, инструменты и перенос.
6. [DESIGN_QA_CHECKLIST.md](DESIGN_QA_CHECKLIST.md) — перед сдачей изменения.

Числовые значения править в [design/tokens.css](../../design/tokens.css). Документы объясняют их назначение; не создавать параллельный JSON/Tailwind theme с независимыми значениями. [design/foundation.css](../../design/foundation.css) — переносимая основа, [design/preview.html](../../design/preview.html) — образец базовых элементов. [design/index.html](../../design/index.html) — реализованная художественная сцена и нейтральная оболочка без предметной логики.

## Что подготовлено

Правила идентичности, контракты компонентов, CSS-токены, простые доступные элементы, локальный PP Neue Machina Inktrap и архитектурные ассеты. По последнему уточнению пользователя шрифт един для всех элементов; утверждена иерархия Б — 32/24/16 px. Происхождение шрифта и границы локального использования записаны рядом с файлом. Главная сцена использует Bayer-дизеринг Canvas 2D; на ПК фотография целиком помещается без обрезки, на узком экране кадр заполняет область. Заголовок `localhost3000` и действие `CONNECT` — текст. Проверка новой сцены отражается отдельно от предыдущих браузерных отчётов. Действие сохраняет доступ в нейтральную оболочку, поддержку клавиатуры и историю. Prism Glass реализован отдельным WebGL-сэмплером над собственной архитектурной подложкой: линза, слабое разделение каналов на контрастных краях, нейтральный блик, читаемый DOM-текст и непрозрачный fallback. Постоянного render loop нет. Дополнительно подготовлена изолированная страница [Dashboard](../../design/dashboard/README.md) со сменяемыми демо-данными и переиспользуемыми компонентами; она не задаёт продуктовые разделы.

Дизайн подключён к `AGENTS.md`, корневым `PRODUCT.md`/`DESIGN.md` и проектным навыкам разработки/приёмки. Исходники экспорта и тесты: [design/tooling/README.md](../../design/tooling/README.md). Статус и границы проверок: [VERIFICATION.md](VERIFICATION.md).

## Что остаётся за границами

Конкурсное приложение, его данные и навигация ждут ТЗ. Ссылка `CONNECT` открывает статичную форму входа; вход и регистрация пока не подключены к backend и не отправляют данные. Нейтральная оболочка по-прежнему доступна отдельно через `#workspace`. Favicon оставлен до отдельного решения о форме. Предыдущие ассеты проверены агентом в браузере; проверку новых страниц фиксировать отдельно от прежней. Реальный Safari, экранный диктор, физическое слабое устройство и настоящий toolbar zoom требуют отдельной среды; не подменять их результатами WebKit/CSS zoom/эмуляции.

Страницы ошибок в [design/errors/](../../design/errors/) — независимый статический образец общего шаблона, а не маршруты конкурсного приложения. Они сохраняют основную разметку без JavaScript и используют те же токены и кнопки.

Важнейший запрет: **никаких мелких декоративных подписей**, случайных статусов, индексов или псевдосистемных сообщений. Полезный текст — от 16 CSS px.
