# Руководство реализации

## Стек приложения

Серверная часть использует FastAPI и SQLite. Интерфейс собран на HTML, CSS и нативных ES-модулях без React и отдельной сборки. Запуск описан в [README](../../README.md), путь для проверяющего — в [сценарии демо](../demo.md).

## Дизайн-система

- Общие значения цветов, типографики, размеров и движения берутся из `design/tokens.css`.
- Базовые стили подключаются из `design/foundation.css`; не создавайте параллельные наборы токенов.
- Используйте локальный PP Neue Machina Inktrap и существующие компоненты из `docs/design/COMPONENTS.md`.
- Новые эффекты должны следовать [каталогу эффектов](EFFECTS.md) и сохранять поддержку reduced motion.

## Качество интерфейса

Для изменений интерфейса проверьте узкий и широкий экран, клавиатурную навигацию, видимый фокус, контраст и масштабирование. Используйте [чеклист дизайн-проверки](DESIGN_QA_CHECKLIST.md) и проверьте ключевой пользовательский путь из `docs/demo.md` в браузере.

Перед локальным коммитом выполните `python scripts/check.py` и `git diff --check`. Результаты инфраструктурных и публичных проверок указывайте отдельно от локальных.
