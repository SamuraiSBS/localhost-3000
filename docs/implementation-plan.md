# План реализации

## Подготовка инфраструктуры

- Репозиторий, документы, правила и локальные навыки.
- Заменяемый probe, Docker/Caddy, локальные проверки.
- CI со сборкой, smoke и проверкой отката; публикация immutable GHCR-образа.
- После создания VPS: bootstrap, доступ, DNS, HTTPS, CD, два последовательных публичных деплоя.

## После получения ТЗ

Предметный план пока не заполнен. Порядок: регламент → критерии → пользовательский сценарий MVP → стек/архитектура → вертикальный срез → обязательные интеграции → приёмка и репетиция демонстрации. Для каждой задачи добавить зависимости и критерий готовности.
