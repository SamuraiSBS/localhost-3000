- При конфигурации Tailnet ограничить OIDC credential тегом `tag:localhost3000-ci`, destination `tag:localhost3000-prod`, TCP 22 и пользователя `deploy`. Если в существующем Tailnet есть другие устройства, сначала сверить ACL: широкая политика по умолчанию не подходит для изоляции production.
